# Support

Use the right channel for the type of help you need.

## Project Bugs

Open an issue in the affected public repository. Include:

- What happened
- What you expected
- Steps to reproduce
- Screenshots or logs when useful
- Environment details if the bug depends on OS, Node, Python, browser, or Discord permissions

## Discord or Community Help

Use the AbuSwe7l community support path for server-specific questions, member issues, permissions, roles, tickets, or moderation requests.

Don't put private member data, server logs, tokens, or staff-only screenshots in public GitHub issues.

## Security Reports

Email `support@abuswe7l.com`. Don't open a public issue for vulnerabilities.

## Private or Staged Projects

Some work may be private or not ready for public contribution. Ask a maintainer for the correct repo, scope, and access path before starting work.
